# Kon Labs · Site

Site institucional da Kon, na nova identidade visual (símbolo Foco, feixe verde, carvão e névoa).

Site estático, sem build. Para publicar na Vercel, importe este repositório e mantenha as configurações padrão (o `vercel.json` já ativa URLs limpas).

Para ver localmente:

```
python3 -m http.server 8000
```

e abra http://localhost:8000.
